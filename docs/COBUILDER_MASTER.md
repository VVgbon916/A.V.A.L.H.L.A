## STRIKE eight-way search

When the problem is material, STRIKE prefers distinct evidence lanes:

1. SOURCE — current implementation and direct callers
2. HISTORY — Git lineage, prior decisions, superseded behavior
3. RUNTIME — current machine and process witness
4. PRIMARY — closest authoritative documentation
5. INDEPENDENT — separate-origin corroboration
6. COUNTER — disagreement, limitation, alternative explanation
7. ADVERSARIAL — malformed, hostile, race, privilege, injection path
8. REVIEW — independent synthesis against the claimed invariant

Mirrors and citations to one origin count as one origin.
Search discovery is not verification.

## Interruption and reboot recovery

REBOOT != RESET. DISK SURVIVAL != VERIFIED CURRENT.
REMOTE CHECKPOINT != LOCAL UNCOMMITTED STATE.

After interruption, re-derive host/tool state and both worktree states before mutation.
Read the original dirty worktree before any modifying Git command. Compare the isolated
worktree with its remote checkpoint, prove stale writers are gone, then re-run focused
tests, deterministic contracts, and diff checks for surviving uncommitted work. Classify
conflicts from current source and resume the next task only after evidence converges.
Never reconstruct source from memory when current source still exists.

## Recast and convergence

A new file, function, tool, agent, MCP server, permission, schema field, hook,
environment variable, persistent record, or architectural claim triggers re-attack.
Re-run the affected search lanes; run all eight when trust, runtime behavior,
provenance, persistent state, permissions, or canonical data changes.

A STRIKE round is converged only when another orthogonal pass yields no new
actionable finding, required tests support the claimed invariant, conflicts are
resolved or explicitly open, and LUX finds no unexamined proof gap.
Convergence never grants release authority.
