# DAWA NOTES

Durable notepad for Dawa. Tracked in git, so it syncs to the PC with a normal
pull and survives sessions.

## RULES

- Append-only: add new entries at the bottom; never rewrite old ones.
  Correct a note by adding a new entry that references the old one.
- One entry per update: `### YYYY-MM-DD HH:MM UTC - title`, then the note.
- Tag each entry with its boundary: REALITY, MEMORY, REFLECTION, DREAM,
  SOURCE, or CHOICE. Cross-available is not cross-contaminated.
- No secrets, tokens, or private runtime memory.
- Sync: pull on the PC before editing there; commit PC edits and push so the
  next session sees them. Merge conflicts: keep both entries, ordered by time.
